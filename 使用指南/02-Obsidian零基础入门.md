# 02 - Obsidian 零基础入门

> 目标：会用 Obsidian 记笔记，理解"仓库"概念。

## 第 1 步：打开 Obsidian，打开你的第一个仓库（Vault）

1. 开始菜单搜索 **Obsidian** 并打开
2. 首页选择 **Open folder as vault**（打开文件夹作为仓库）
3. 选择这个文件夹：`C:\Users\1\Obsidian笔记库`
4. 点"信任并打开"——**你现在已经在这个教程仓库里了**，左侧能看到《使用指南》里的几篇笔记

> 💡 "仓库"就是一个普通文件夹，里面所有笔记都是 `.md` 纯文本文件，用记事本都能打开，永远不怕被软件绑架。

## 第 2 步：学会 4 个基本动作

| 动作 | 怎么做 | 说明 |
|---|---|---|
| 新建笔记 | 左上角"新建笔记"图标 或 `Ctrl + N` | 起个标题就能写 |
| 双向链接 | 输入 `[[` 会弹出笔记列表 | 把两篇笔记连起来，这是 Obsidian 的灵魂功能 |
| 标签 | 在笔记里写 `#标签名` | 右侧面板能按标签聚合 |
| 全局搜索 | `Ctrl + Shift + F` | 搜所有笔记内容 |

## 第 3 步：体验一下双向链接

1. 新建一篇笔记，输入：`今天学了 [[00-三件套总览|三件套的用法]]`
2. 切到《00-三件套总览》，右侧"反向链接"面板会显示谁引用了它
3. 用久了会形成自己的知识网络（点右上角"关系图谱"图标看看效果）

## 第 4 步（可选）：安装两个关键社区插件

> 需要联网，每个插件装一次即可。

**装插件的通用路径**：左下角齿轮（设置）→ 第三方插件（Community plugins）→ 关闭受限模式（Turn on community plugins）→ Browse 搜索安装。

### 插件 A：Obsidian Git（自动备份）
- 搜索 `Obsidian Git` 安装并启用
- 作用：在 Obsidian 界面里直接完成 Git 提交/推送，还能设置"每 N 分钟自动备份"
- 前提：先完成 [01-GitHub零基础入门](01-GitHub零基础入门.md) 的配置

### 插件 B：Copilot（本地 AI 助手入口）
- 搜索 `Copilot`（作者 Logan Yang）安装并启用
- 进它的设置 → 模型/提供商选 **Custom OpenAI 格式**（自定义 OpenAI 兼容接口）
- 地址填：`http://127.0.0.1:8899/v1`，API Key 随便填一个（如 `local`），模型名填 `hermes3`
- 详细步骤见 [03-Hermes本地AI零基础入门](03-Hermes本地AI零基础入门.md)

## 界面速查

- 左侧栏：笔记文件列表
- 中间：编辑区
- 右侧栏：反向链接、大纲、标签
- `Ctrl + P`：命令面板（记不住功能时按它，搜索想要的操作）
