# 03 - Hermes 本地 AI 零基础入门

> 目标：启动本地 AI 服务，并在任何支持"OpenAI 兼容接口"的软件里使用它。
>
> 你的电脑配置（32GB 内存、无独立显卡）实测生成速度约 **7 字/秒**，够日常总结、问答使用。

## 它是什么

- **Hermes 3 8B** 是 Nous Research 开源的大语言模型，已经下载到你的电脑上（4.6GB）
- 用 llama.cpp 引擎在本地运行，**不需要联网、不花钱、聊天内容不上传任何服务器**

## 第 1 步：启动服务（10 秒）

双击这个文件：

```
C:\Users\1\WorkBuddy\2026-11-13-14-01-44\hermes-local\启动Hermes服务.bat
```

- 会弹出一个黑色窗口，等模型加载完（约 1 分钟）
- 看到 `listening on http://127.0.0.1:8899` 就说明启动成功
- **用完后直接关掉黑窗口就是停止服务**（不占任何后台资源）

> 💡 可以右键这个 bat → 发送到 → 桌面快捷方式，以后从桌面启动。

## 第 2 步：认识三个关键参数（配置其他软件时要用）

| 参数 | 值 |
|---|---|
| 接口地址（Base URL） | `http://127.0.0.1:8899/v1` |
| API Key | 随便填，比如 `local`（本地服务不校验） |
| 模型名（Model） | 随便填，比如 `hermes3`（只有一个模型） |

## 第 3 步：三种使用方式（按简单程度排序）

### 方式 A：在 Obsidian 里用（推荐，见工作流 2）

装好 Copilot 插件后（见 [02-Obsidian零基础入门](02-Obsidian零基础入门.md)），在笔记里选中文本就能让 AI 总结/续写/翻译。

### 方式 B：用命令行快速提问（测试用）

启动服务后，另开一个命令行窗口执行（把问题换成你自己的）：

```bash
curl http://127.0.0.1:8899/v1/chat/completions -H "Content-Type: application/json" -d "{\"messages\":[{\"role\":\"user\",\"content\":\"你好，介绍一下你自己\"}]}"
```

### 方式 C：对接任何支持"自定义 OpenAI 接口"的软件

很多 AI 客户端（ChatBox、LobeChat、沉浸式翻译等）都支持自定义接口，填上面第 2 步的三个参数即可。

## 使用建议（让 7 字/秒发挥最大价值）

✅ 适合交给 Hermes 的任务：
- 总结一段笔记 / 一篇文章的要点
- 润色、改写、翻译文字
- 根据关键词生成日记框架、周报模板
- 头脑风暴、列清单

⚠️ 不太适合的任务：
- 超长文章（一次别超过几千字，上下文设了 4096 tokens）
- 需要最新信息的问答（模型是本地的，不知道今天的新闻）
- 复杂推理（8B 模型能力有限，胜在隐私和离线）

## 常见问题

- **黑色窗口一关服务就没了？** 是的，这是设计如此。想常驻就用方式 A/C 的软件调用前先把它打开。
- **能换更强的模型吗？** 可以，以后从魔搭（modelscope.cn）下载其他 GGUF 模型文件放进 `models` 文件夹，改 bat 里的文件名即可。
