# 04 - 三件套协同实操

> 前置条件：完成 [01-GitHub零基础入门](01-GitHub零基础入门.md)（GitHub 账号 + SSH 密钥 + Git 署名）。
> 这一篇把三条工作流真正跑起来。

## 实操 1：给这个笔记库上"双保险"（Git + GitHub）⭐ 15 分钟

### 1.1 创建 GitHub 私有仓库
1. 打开 https://github.com/new
2. Repository name 填：`my-notes`
3. 勾选 **Private**（私有，只有你能看）
4. 点 **Create repository**，**不要**勾选任何初始化选项（README、.gitignore 都不勾）

### 1.2 本地关联并首次上传
按 `Win + R` 输入 `cmd`，逐行执行：

```bash
cd C:\Users\1\Obsidian笔记库
git init
git add .
git commit -m "初始化笔记库：三件套使用指南"
git branch -M main
git remote add origin git@github.com:你的用户名/my-notes.git
git push -u origin main
```

刷新 GitHub 网页，你的笔记已经在云端了 ✅

### 1.3 以后的日常备份（一条命令）
```bash
cd C:\Users\1\Obsidian笔记库
git add . && git commit -m "更新笔记" && git push
```

> 装了 Obsidian Git 插件后，这一步会自动定时执行，可以完全忘掉。

## 实操 2：让 Hermes 在 Obsidian 里上岗（AI 笔记助手）⭐ 10 分钟

1. 双击 `启动Hermes服务.bat`，等它加载完
2. 打开 Obsidian → 设置 → 第三方插件 → 装好 **Copilot**
3. Copilot 设置里：
   - 提供商：Custom OpenAI / OpenAI 格式
   - Base URL：`http://127.0.0.1:8899/v1`
   - API Key：`local`（随便填）
   - 模型：`hermes3`
4. 回到笔记，选中一段文字 → 右键/快捷键 → 让 AI "总结这段话"

**试一试**：选中本文件上面任何一段，让 Hermes 给你生成 3 条要点。

## 实操 3：每日闭环（把三件套串起来）

每天流程（总耗时 < 10 分钟）：

1. **记**：白天在 Obsidian 随手记（新建 `日记/2026-11-13.md` 这样的笔记）
2. **炼**：晚上打开 Hermes 服务，让 AI 把当天碎片笔记总结成一段"今日回顾"，粘到日记末尾
3. **存**：Obsidian Git 自动提交推送 → GitHub 云端已有今天的全部记录

一个月后你会发现：所有笔记有 AI 摘要、有历史版本、有云端备份——这就是三件套的最大价值。

## 玩转之后的进阶方向（选读）

- **模板**：Obsidian 核心插件"模板"功能，让 AI 生成的总结有固定格式
- **图谱**：笔记多了以后看"关系图谱"，视觉化你的知识网络
- **更强的模型**：内存 32GB 其实能跑 14B 模型（如 Hermes 4 14B），从魔搭下载后替换即可
- **手机同步**：手机装 Obsidian + Git 客户端（如 MGit），通过同一个 GitHub 仓库多端同步

## 出问题时怎么办

| 问题 | 解决 |
|---|---|
| `git push` 报 Permission denied | SSH 密钥没配好，回到 [01-GitHub零基础入门](01-GitHub零基础入门.md) 第 1 步 |
| Copilot 连不上 AI | Hermes 服务的黑窗口没开，先双击 bat |
| AI 回复很慢 | 正常，7 字/秒；请它"总结"而不是"写长文" |
| Obsidian 误删笔记 | 别慌，`git log` 找历史版本恢复 |
